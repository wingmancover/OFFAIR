# 双房间区域循环与会话存档（第 2～4 步）

2026-11-08。适用地图 `/Game/OFFAIR/Levels/Lvl_TwoRoom_Blockout`，不改变旧 `Lvl_Prototype` 的三阶段规则。用户已确认布局并授权实现、测试和保存；Git 提交、上传由用户处理。本轮不打包。

## 已实现与边界

- 首次看向 3.3 m 内、无遮挡的红色信件，E 阅读；纸条消失，三秒记忆过载期间锁移动、视角、跳跃和交互，随后死亡并回到 A。
- A—B 区域恢复固定初始状态；保留“经历过首次记忆死亡”和死亡次数。之后信件可跳过；再次阅读不会再触发强制死亡。
- 玩家不能用 R 主动循环。GM 的 F1 → 1、伤害归零和掉出测试区域共用死亡入口。重置期间拒绝重复请求；尝试编号隔离上一轮延迟事件和生成物。
- B 需要首次记忆、枪、权限卡、摄像头学习、谜题成功五项条件。看向 B 终端、距离不超过 3.6 m，按 E 才保存；走近或 GM 传送都不保存。
- B 仅保存在当前 PIE／游戏会话。B 后死亡回到 B，恢复存档时的玩家进度，已完成区域保留现场。退出 PIE／关闭游戏清空，不支持磁盘读档或后期自由瞬移。
- 原创短音效覆盖死亡／循环、B 保存和黑入／退出；枪声复用模板。已有必要的主持人／心理文字引导，没有配音、音乐或完整叙事系统。

第 3 步已接入两把可用手枪、10／2 名守卫、清场掉卡和 C1 正式黑入教学，具体条件见[教学房与 GM](region-tutorial.md)。第 4 步已接入 C2 找图案、真实射击解谜与错误答案循环，正常路线可以开放 D2 并保存 B，见[谜题房](region-puzzle.md)。完整叙事 UI 与观景镜头留待后续。

基准登记不是死亡时的现场快照。新增参与者必须加入登记列表，或实现后续功能自己的显式状态恢复；不能只凭位置自动纳入循环。基准 Actor 不应被销毁，而应隐藏并禁用碰撞；意外丢失会明确报错，要求重启 PIE，不以部分重置继续运行。

`ReportRegionProgress(AttemptId, Kind)` 按枪→卡→摄像头→谜题的依赖接受事件。`RegisterRegionTransient` 登记本轮生成物；旧编号对象会被拒绝并销毁。第 3 步已接入战斗、卡和 C1 学习生产者；第 4 步已接入真实谜题提交完成条件。

## 控制与本轮试玩

WASD 移动、鼠标观察、空格跳跃、E 交互、LMB 射击、E／Q 退出摄像头、F1 开关 GM。**R 无作用**。新地图翻越仍待复用接入；旧地图的空格翻越保留。

正常路线为首次红信死亡 → 选枪 → 清场 → E 拾卡 → 看向 C1、E 黑入 → 转动至少 10°、正常退出 → D1 开放，进入谜题房。完整试玩步骤、GM 1～7 对照及状态恢复见[第 3 步说明](region-tutorial.md)。普通 HUD 使用实时字体与深色底板；GM 保留调试风格，仅 F1 显示。完整 UI 风格在第 5 步处理。

B 测试：首次记忆后 F1 → 2 授予明确标记的测试条件；3 传送附近、看向 B 终端 E 保存；1 测试 B 后死亡。该过程只验会话存档，不验正常解谜通关。

## 空间调整

- 巨蛋背景占地面积减半，水平边长／半径乘 √0.5。背景方形基准从 1080 m 边长变为约 764 m，穹顶高度保留；局部两房间、直角过道与观景台不变。
- `OA_TruePatternBack` 移到谜题房北侧遮挡柜上部，第 4 步板心微调为 `(7600,6100,500)` cm；碎片位于板前三个深度平面。外壳本身可见，答案背板和碎片只对 C2 所有权链对应的观察视角显示，避免跳跃、绕行或未来自由观察泄露答案。
- 第 3 步 C2 光学点为 `(7442,4315,320)`、yaw 20°、pitch −15°，初始不朝向正确图案。GM 7 可转动预览，第 4 步正式构图／射击已接入，视野角 50°。
