# 第 5 步：游玩界面、逐句叙事与 B 后观景

2026-11-08，适用 `Lvl_TwoRoom_Blockout`。用户确认第 4 步并已保存上传，授权本步实现、测试、保存；Git 提交和上传由用户处理，不打包。

## 2026-11-09 试玩修正

- 谜题通用操作说明移到左上目标区，取消房间内常驻中央提示；实际看向物品／控制台时的 E 交互提示保留。
- C1 每轮首次正常完成时仍播放主持人引导；同一轮反复进出不重复完成事件。只有主角的摄像头发现心理对白跨死亡只触发一次；权限卡的首次发现心理对白也只触发一次。`CameraLessonNarrated`／`CardDiscoveryNarrated` 作为经历在死亡后保留，新 PIE 清空；并不保留卡或开门条件，每次未存档重试仍需取卡、转动并退出 C1。未转动时用系统操作提示，不重复内心独白。
- 观景终点由 14 m 提高到 145 m，并继续后退，视野角设为 95°，抬高观察焦点以同时看到竞技场与巨蛋轮廓。关闭观景相机固定宽高比，避免宽编辑器窗口出现左右黑边；HUD 仅上下各遮住画面高度的 1/18，16:9 对应可见 16:8，宽窗口也保留整幅宽度。

## 2026-11-09 叙事顺序补充

用户澄清：主持人不知道循环，跨死亡再次完成 C1 应保留主持人台词，只抑制主角已经经历过的发现。C1 玩法完成状态依旧每轮重置。

C2 对齐后的心理文字按实际作答状态决定：未填对且未解决时提示复现图案；已填对、尚未提交时确认 “That matches what I've already entered. I can submit it now.”；已经提交成功后不再新增 L 的使用指导。观察状态仍正常记录，不影响摄像头控制、已开门或成功主持人台词。前两种指导附带实时条件，填对、清空或提交会取消已经过时的当前句子及排队句子。

## 单一字幕通道

- 主持人与主角共用下方同一张字幕卡，一次只显示一句。主持人标签 `HOST / BROADCAST` 配琥珀色，主角标签 `INNER VOICE` 配青色，正文为浅色。
- 主持人先说，主角再回应；例如谜题房先推荐琥珀色参考图、说明错误有致命后果，之后主角怀疑并想到摄像头。找出真图案后的新信息会替换尚未播出的过时怀疑。
- 按句子拆分，停留时间随英文词数变化，常规每句 2.5～7 秒，句间留白 0.3 秒。排队上限 12 句，重复触发不重复排入同一句。
- 对白带尝试编号、目标语境和可选有效条件。玩家已取枪、拾卡、解谜或保存时，过时指令从当前字幕与待播队列中移除。快速推进允许省略已失去意义的引导，不把上一地点的指令积压到之后播放。
- 记忆过载、死亡清空全部对白；复活只产生本轮合适的心理文字。主持人仍不知道循环，只评论当轮行为。
- GM 提示、条件不足、清空面板和 B 保存属于短系统通知，不冒充主角内心。错误答案只播简短的 “Wrong answer.”，保留已经确认的 1.4 秒惩罚反馈时长。
- 当前仍是文字叙事，没有新增配音或音乐。已有关键音效继续使用。

`HostText`／`ThoughtText` 保留为旧测试兼容的最近事件诊断，不直接绘制。真实屏幕由 `SubtitleText`／`SubtitleSpeaker` 和队列驱动，不能用诊断字段同时有值推断画面重叠。

## HUD 信息层级

左上为紧凑的当前目标，左下血量条与数值、右下弹药。中央保留小准星、当前交互提示；操作说明按当前情境显示，不再常驻整条键位列表。摄像头视角使用右上连接状态、返回提示和取景标记。GM 默认隐藏，仅 F1 打开，使用清晰字体保留原有功能。

字幕卡按可用宽度换行，限制宽度并与交互、血量和弹药分开。字体复用已有运行时字体，布局随窗口尺寸缩放。没有修改项目画质、分辨率默认值或渲染平台设置。

## B 保存后的观景镜头

1. 正常解谜开门，玩家看向记忆终端按 E，先完成 B 的会话存档。此时目标变为走上观景平台；走过门或接近 B 均不替代保存。
2. 已保存且走入平台观景触发区后，一次性开始镜头。复用已批准的 K1／K2：从 `(10400,4400,170)` 拉到 `(-1000,1000,14500)` cm，观察低地和巨蛋内部。焦点为单独可编辑的 `OA_VistaFocus`，当前 `(24000,6500,4000)`。
3. 五秒平滑拉高拉远、两秒停留、一秒回到本体，总计约八秒。镜头期间隐藏常规 HUD，保留一张字幕和跳过提示；主持人介绍主竞技场，随后主角回应。
4. **空格**可跳过，也接受已有交互／退出键 E、Q；用一秒平滑回到角色。拉镜头不传送玩家，本体停在安全平台上；移动、观察、跳跃、交互、射击暂时锁定，返回后恢复。
5. 一次会话只自动播放一次。跳过、死亡或设备异常都不会取消已完成的 B 保存；正常结束、跳过、死亡和目标失效均清理镜头状态并恢复角色视角。重复进出平台不反复播放。
6. B 保存后但尚未走上平台便死亡，仍可在复活后触发镜头；一旦镜头开始便记为已播放，避免死亡重播。新 PIE 清空播放记录，与 B 的会话保存范围一致。

镜头中仍可 F1 → 1 测试死亡；其他 GM 操作暂时不执行，避免多个视角控制者竞争。镜头不是新的正式主动循环能力，也不是整关最终维修通道出口。

## 状态与资产职责

| 状态 | 死亡／中断 | B 保存／新会话 |
| --- | --- | --- |
| 当前字幕、排队句子、句间计时 | 清空；拒绝旧尝试句子 | 保存 B 时切换到记忆语境；新会话清空 |
| 系统通知 | 死亡清空，普通超时消失 | 不作为进度保存 |
| 观景阶段、计时、视角与输入锁 | 取消并回到本体；没有遗留计时回调 | B 先保存；新会话初始 |
| 已播放记录 | 开始后保留，阻止重复播放 | 当前会话保留，新会话清空 |
| 角色位置与已保存玩法 | 镜头不修改位置／物品／谜题 | 依旧由区域循环与 B 规则管理 |
