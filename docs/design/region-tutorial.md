# 双房间第 3 步：教学房与 GM

适用 `Lvl_TwoRoom_Blockout`。本轮接入正常选枪、战斗、掉卡与 C1 摄像头教学；不打包，不提交或推送 Git。旧 `Lvl_Prototype` 保留。循环底层见[区域循环](region-loop-checkpoint.md)，初次验证见[第 3 步记录](../qa/region-tutorial-validation.md)，本轮修复见[反馈回归](../qa/region-tutorial-fixes-validation.md)。

## 正常试玩路线

1. 从 A 出生，首次必须看向红信按 E。三秒记忆过载锁定操作，死亡后回到 A；之后可以跳过信件。枪和信件开局同时存在，首次记忆之前枪不可取。
2. 走到枪台前，准星看向枪模型，3.5 m 内无遮挡按 E。每次尝试只选一把，两把展示枪同时收起，获得一把可用手枪。
3. 主持人推荐琥珀色枪；选它生成 10 名守卫。青色枪生成 2 名。两把枪性能一致，不以无敌或强制死亡实现陷阱；守卫数量是本轮压力参数，可根据试玩调节。
4. 鼠标左键射击，模板手枪每发伤害 25，守卫生命 100，玩家生命 500；保留模板弹匣 10 发及自动补满行为。击杀本轮全部守卫后，最后一名守卫所在位置出现一张金色权限卡。看向卡、3.5 m 内按 E 收取。
5. 看向教学房 C1 摄像头，20 m 内且无遮挡按 E 黑入。鼠标转动镜头；E 或 Q 返回本体。至少转动 10° 并正常退出，才完成摄像头教学、开放 D1。只连接并立即退出不算完成。
6. 通过直角过道进入 Signal Lab。第 4 步已继续接入 C2、射击谜题、主动提交与正常 B 保存；详见[谜题房](region-puzzle.md)。观景镜头仍留待第 5 步。

玩家没有 R 主动循环。死亡重试时，枪、敌人、卡、门、摄像头朝向等未保存状态恢复初始值；首次记忆经历和选枪经验保留。主持人只评论当前行为，主角心理文字提供跨循环知识引导。

## GM 与测试

F1 开关 GM，默认隐藏；数字快捷键只在面板打开时有效。GM 不暂停战斗。

| 按键 | 行为与边界 |
| --- | --- |
| 1 | 测试死亡，走同一死亡与重置入口 |
| 2 | 首次记忆后授予 B 的测试条件，装备真实青色手枪、开放两道门；明确标为 GM 测试，不能作为谜题通过证据 |
| 3 | 传送到 B 附近，仍须看向终端按 E 保存 |
| 4 | 教学战斗中增加一名守卫，计入本轮清场要求；最多 16 个登记实例 |
| 5 | 移除活守卫，不计击杀；本轮掉卡资格作废，须重试以恢复正常战斗 |
| 6 | 接入教学 C1，跳过距离与卡入口；未持卡不授予教学完成条件 |
| 7 | 接入谜题 C2，初始不朝向真图案；跳过连接入口，不授予枪／卡／C1，不自动解谜 |

6／7 会关闭 GM 面板以便操控；E／Q 退出。测试远程死亡可再按 F1 → 1。当前不提供数字“前后阶段”，因为新地图按 A—B 区域重试，不使用旧图三阶段编号。

## 本轮试玩反馈修复

- 无论拿过哪把枪，B 前死亡／GM 1 重试都恢复开局第一、第三人称空手动画；B 存档后仍恢复已保存的枪和对应持枪动画。
- 琥珀色路线为 10 名守卫，青色仍为 2 名。琥珀色清场使用专属主持人台词：
  “Ten guards, and you're still standing! Now THAT is a performance. Your access card is well earned.”
  台词评论当前轮表现，不透露主持人知道循环；不增加强制死亡或无敌敌人。
- 重置时立即隐藏子弹、关闭碰撞、停止运动和时间轴，在导演下一次 Tick 再销毁，避免致死命中／延迟效果调用栈内销毁其组件。新队列在下一次 Tick 清空；不跨循环、存档或会话保留。
- 两个新增出生点 E9 `(4350,2850,100)`、E10 `(4350,750,100)`；原有房间摆位、两枪性能、生命和伤害未调整。

## UI、叙事与声音

- 普通 HUD：实时字体缓存的 26／20 号字体，以 1 倍绘制，替换放大小号 Canvas 字体的方式；目标、血量／弹药、交互与字幕用深色底板。模糊不是 Python 运行造成的，Python 仅参与资产作者流程。
- 主持人文字为琥珀色，主角心理文字为青色。主持人覆盖进入房间、推荐枪、选枪反应、清场取卡、摄像头目标与教学完成；主角在首次复活、琥珀枪失败、取卡与教学后提供自我引导。没有配音。
- GM 保留调试字体与状态值，仅 F1 显示。完整 UI 风格、字幕系统、叙事时序扩展仍在第 5 步。
- 保留循环和存档音效，新增原创短音效黑入／退出，枪械复用模板声音。

## 状态与职责

| 内容 | B 前死亡 | B 保存后死亡 |
| --- | --- | --- |
| 本轮枪与弹药 | 销毁持枪与旧射击计时，清空库存；两把展示枪恢复 | 按保存的选择重新装备，补满弹匣 |
| 守卫、控制器、尸体 | 清理本轮登记的全部实例 | 完成区域不重建战斗 |
| 子弹 | 死亡／保存时清理；旧或未知射手注册拒绝 | 同样清理飞行中的子弹 |
| 卡、击杀数、掉卡资格、D1 | 清空进度、隐藏卡、关闭门 | 保留已完成状态与玩家卡权限 |
| C1／C2 朝向、远程与输入 | 恢复作者初始朝向，清理远程并返回本体 | 保留设备方向，清理远程输入 |
| 主持人临时文字 | 清理；再次接近枪台重新引导 | 清理 |
| 首次记忆、上次选枪经验 | 保留，只影响后续引导，不保留物品 | 保留 |

`RegionLoopDirector.cs` 负责状态与交互，`BP_RegionLoopDirector` 的小型适配函数调用模板。`BP_RegionShooterCharacter` 继承 Shooter 角色；三种手枪子类、`BP_RegionGuard`、`BP_RegionBullet` 继承对应模板，避免修改第三方／模板蓝图。C# 伤害桥接替代模板延迟销毁玩家，确保复活只有一个入口。

`Tools/unreal/build_region_tutorial.py` 是本轮增量作者脚本：保存蓝图、引用、D1／卡及两个额外守卫点，不重建房间或巨蛋。需要先编译托管代码。基础 `build_region_loop.py` 完整运行后会接着装配第三步，防止下一次生成退回仅进度旗标的状态。日常微调不要重跑全量布局生成器。

C1 光学点 `(4265,2665,320)`，初始 yaw 225°、pitch −12°。C2 光学点 `(7442,4315,320)`，初始 yaw 20°、pitch −15°；真图案仍只有 C2 所有权视角可见。教学黑入不包含射击解谜。
