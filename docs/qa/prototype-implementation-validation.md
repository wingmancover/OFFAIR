## 图形界面与输入

已在有画面 PIE 中通过操作系统级键鼠输入验证，未用交互函数调用替代这些检查：

| 操作 | 实际结果 |
| --- | --- |
| 点击视口、按 E 取得核心 | 核心消失，提示下一次死亡推进；仍为阶段 0 |
| 按 R | 进入重置画面；新世界为阶段 1，守卫存在，远程控制关闭 |
| 按 F1 | GM 开关有效，画面保持 Lit，不触发引擎线框模式 |
| 鼠标点击下一／上一阶段 | 分别恢复阶段 1／0，敌人数回到相应初始值 |
| 鼠标点击黑入 | 切到监控实际位置，自动收起 GM；镜头不被自身模型遮挡 |
| 移动鼠标 | 水平从 180° 变为约 190.97°，俯仰从 -18° 变为约 -18.86°，本体位置未变 |
| 按 Q，再按 E、R | 返回本体后交互恢复；正常拾取与死亡推进仍可使用 |

远程输入与重置后的状态分别保存在[鼠标转向状态](evidence/prototype-remote-input.json)、[键盘重置状态](evidence/prototype-after-keyboard-reset.json)。原生引擎截图见[GM 面板](evidence/prototype-gm-panel.png)与[监控视角](evidence/prototype-remote-view.png)；这两张图来自 GM 界面检查，不作为正常通关的替代证据。

GM 打开时显式采用 Game And UI 输入模式，关闭后恢复 Game Only。自动化工具在浮动窗口曾出现坐标偏移，因此最后的按钮定位检查在最大化窗口中逐次核对画面与状态。没有据此声称完成所有显示缩放／分辨率的兼容测试。

## 修复与验证边界

本轮修复了模板自动重生与阶段重置的重复职责、终端通行空间、导航代理尺寸及注册时序、输入键值序列化、F1 引擎调试绑定冲突、场景文字旋转、远程视角中设备模型遮挡和测试恢复窗口的判定问题。生成工具保留函数身份，避免重复生成导致跨蓝图调用失效。

重新核对了盘点中 19 个原模板蓝图的 SHA-256，全部与实现前一致。最终构建、导航与 PIE 日志未发现 Blueprint Error、Accessed None 或 Python Traceback；生成器 Python 语法检查通过。

当前没有制作完整剧情或成品美术，没有跨进程存档，也没有将地图拓展为任意阶段／分支编辑器。未进行独立打包发布验证、第三方试玩或多机性能验收；不能将 PIE 结果表述为这些工作已完成。
