# 第 5 步：界面、逐句叙事与观景验证

2026-11-08，Windows x64，UE 5.8.4，`Lvl_TwoRoom_Blockout`。本轮保存项目，不打包，不暂存、提交或推送 Git。行为与状态策略见[呈现规范](../design/region-presentation.md)。

## 实际验证方式

- 托管构建成功；增量作者脚本添加观景相机、触发范围和焦点，保存地图，编译导演与 HUD。没有重建房间或修改模板资产。
- `Tools/unreal/validate_region_presentation.py` 在离屏渲染 PIE 中运行，经过正常红信、青色枪、实际子弹清场、拾卡、C1 教学、C2 寻图、射击正确答案与 E 保存 B，再由角色移动走上平台。
- 输入通过运行时处理入口调用；未向桌面发送物理键鼠。测试部分定位使用传送夹具，射击准确性阶段暂停守卫 AI。它证明相关交互、真实弹丸和状态衔接，不等同于人工完整试玩。
- 正常 B 与观景路线没有使用 GM 授予前提。跳过、镜头中死亡和设备销毁的独立异常测试使用显式 GM 准备条件。

## 本步检查

呈现集成 **55 项通过，108.53 秒**。详见[最终结果](evidence/region-presentation-runtime.json)。

| 项目 | 结果 |
| --- | --- |
| 单一字幕 | 主持人推荐假图案 → 主持人说明风险 → 主角想到摄像头 → 主角决定先观察，按句依次显示 |
| 信息有效性 | 快速取枪取消过时取信／选枪引导；解谜取消旧怀疑；死亡清空所有排队句子，新尝试不恢复旧主持人台词 |
| 正常观景 | 未保存 B 不触发；正常保存后走上平台触发；相机升高后退，本体留在平台，射击和移动锁定 |
| 正常恢复 | 自动返回玩家视角，恢复输入；保存、枪、已解谜状态不丢失；留在平台和重新进入不重复播放 |
| 中断边界 | 空格跳过、GM 死亡、销毁观景相机均恢复角色视角；旧镜头计时不再生效；新 PIE 清空播放记录 |

教学回归 **92 项通过，68.34 秒**，包括琥珀 10 名、致命弹丸、复活空手、C1 黑入和 B 装备恢复，见[教学结果](evidence/region-presentation-tutorial-regression.json)。

谜题回归 **83 项通过，109.77 秒**，覆盖假答案死亡、整区重置、真答案／知识直答、C2 中死亡与设备失效、B 保存后保留；见[谜题结果](evidence/region-presentation-puzzle-regression.json)。三套最终 PIE 日志未见蓝图运行时错误、Sphere pending-kill 或 UnrealSharp 运行时异常。辅助编辑器因主编辑器占用 MCP 端口产生的绑定错误，以及已有 StateTree StopLogic 警告单独保留，不宣称日志零警告。主编辑器最终 C# 热重载成功，已重新载入保存后的新地图且 PIE 关闭。

## 用户试玩流程

1. 打开 `Lvl_TwoRoom_Blockout`，开始新的 PIE。检查左上目标、左下血量、右下弹药和中央交互提示；F1 开关 GM，默认不显示调试面板。
2. 正常完成红信、取枪、清场、卡和 C1。留意对白一次一人一句，主持人为琥珀色标签、内心为青色标签。快速推进时过时指令应停止排队。
3. 进入谜题房先稍作停留：应先听取主持人的文字，再看到主角怀疑。C2 寻图、错误死亡、凭知识直答仍沿用第四步；死亡后不应继续显示上轮字幕。
4. 正确解谜后过门，看向 B 终端按 E。**保存后继续走上前方平台**，才自动播放约八秒拉高拉远镜头，之后恢复第一人称与操作。
5. 新开一次 PIE 可再看镜头；播放中按空格应平滑跳过，也接受 E／Q。可 F1 → 1 测死亡：返回 B、完成区域保留，镜头不再自动重播。

本轮没有新增配音或音乐；保留已有关键声音。后台使用 `-nosound`，音量与听感没有验证。物理键鼠、阅读节奏和镜头舒适度待用户确认；没有打包或 macOS 实测。
