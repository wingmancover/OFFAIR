## A「巨幕」字形更新（当前版本）

用户试玩确认初版逻辑后，选择 A 版效果图并授权稍微放大、提高清晰度。当前标题宽度约为屏幕 86%（此前约 80%），采用厚笔画、方圆 O 的原创几何字标。`Tools/art/build_title_wordmark.py` 从相同轮廓生成可编辑 SVG 与 6400×1200 透明 PNG，导入为 `T_OFFAIRTitleA`；HUD 使用透明纹理绘制，旧字体只作为缺失素材时的回退。

纹理使用无损 UI 压缩、关闭 mip 和流送，X／Y 使用 Clamp。首轮 4K 截图发现上下边缘采样到对边像素造成细线，修正 Clamp 后重新运行并检查截图，细线已消失。没有改变全局画质设置或地图布局。本轮只更新字标及绘制，导演的三秒时长、直接出现／消失、控制权限和去重逻辑未改。

托管构建、HUD 编译及主编辑器保存成功。最终后台 PIE **52 项通过，101.38 秒**；三秒标题观测值约 **2.990 秒**（检测帧误差）。原有正常通关、移动射击、字幕暂停／恢复、跳过、死亡、相机失效和新会话分支再次通过，另确认高清纹理引用、尺寸与采样设置。见[最终结果](evidence/region-title-a-runtime.json)。未见蓝图运行时错误或托管异常，辅助进程仍有预期的 MCP 端口占用提示。

## 实际验证

托管构建成功，主编辑器热重载成功；相关蓝图编译通过。字体由后台作者脚本生成，HUD 保存曾因主编辑器占用失败，随后在主编辑器设置字体引用、编译并成功保存。最终再次读取确认引用正确，当前地图无未保存修改、PIE 已关闭。

`Tools/unreal/validate_region_title.py` 在独立后台编辑器执行：**49 项通过，97.62 秒**。见[完整结果](evidence/region-title-runtime.json)。

- 新进程从持久配置自动打开新地图；游戏默认地图、仅含新图的打包列表及旧地图存在性通过。
- 正常路线完成信件死亡、青色枪两名守卫、真实弹丸清场、权限卡、C1、C2、真实射击正确图案及 E 保存 B，再用角色移动走上平台。正常路线没有 GM 授予条件。
- 标题只在返回本体视角后出现，移动／观察输入解锁。角色在标题期间实际移动约 **124.6 cm／0.35 秒**；射击扣除弹药。标题实测 **3.004 秒**后消失。
- 字幕文字及剩余时间在标题期间暂停，结束后继续；HUD 恢复。为明确测试计时，将观景期间已经存在的一句内心对白剩余时间延长为六秒，此项是测试夹具，不修改正式台词时长。
- 跳过后标题正常；重复操作和重返平台不重播。标题中 GM 死亡立即清除，B 状态保留且不重播。
- 观景中死亡、跳过返回途中死亡、观景相机被销毁均不误触发标题；旧计时器不在复活后播放标题。新 PIE 会话恢复未播放状态。
- 最终测试日志未见蓝图运行时错误或托管异常。辅助编辑器无法占用主编辑器的 MCP 端口是已知环境提示，不影响 PIE 验证。

验证复用运行时输入处理入口、真实投射物和 CharacterMovement，包含位置与暂停部分 AI 的夹具；中断分支用明确的 GM 准备场景。没有发送桌面物理按键，不把这些检查称为人工完整试玩。测试脚本早期的配置读取 API 和移动计量问题已修正；上面的通过结果来自最终完整运行。

## 用户试玩

1. 在 `Lvl_TwoRoom_Blockout` 开始新的 Play，正常走完两房间、E 保存 B，再走上观景平台。
2. 让镜头完整播放：回到第一人称时立刻出现 OFFAIR，三秒后直接消失；期间尝试 WASD、鼠标转向及射击。
3. 确认标题期间普通 HUD／字幕隐藏，消失后恢复，没有黑屏或持续锁定输入。
4. 结束 Play 后重新开始，观景时按空格跳过，返回第一人称后同样显示标题。
5. 可选：标题期间 F1 打开 GM，按 1 死亡，标题应立即消失；B 复活后不再播放。重返平台也不重复。

物理键鼠体验、标题尺寸和三秒节奏待用户试玩确认。本轮未测试打包后的 EXE、macOS 或音频；启动／打包配置已验证，不等同于已验证打包成品。
